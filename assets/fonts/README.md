# Fonts

## terminus32x16.bmp

- Font: Terminus Font, 16x32 pixels, Lat15 character set.
- Copyright (C) 2020 Dimitar Toshkov Zhekov, with Reserved Font Name "Terminus Font".
- License: SIL Open Font License, Version 1.1. The full text is in LICENSES/OFL.txt.
- Source: `Lat15-Terminus32x16.psf.gz` from the Debian package `console-setup-linux` 1.221.

This file is a Modified Version of the font. The PSF2 glyphs are converted to a 1-bit BMP image.
The image is a grid of 16 x 16 cells. The cell number is the Latin-1 character code.
